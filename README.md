# 🏨 HotelBookingApp – iOS

HotelBookingApp is a modern iOS application designed to provide a smooth hotel discovery and booking experience.

The app focuses on a clean and user-friendly interface for browsing hotels, viewing hotel details, selecting rooms, and completing the booking flow.

## ✨ Features

* 🏨 Hotel listing
* 🔍 Hotel search
* 📍 Hotel location/details
* 🛏️ Room and hotel details
* ⭐ Hotel ratings and reviews
* 📅 Booking flow
* 💳 Booking/payment UI
* 👤 User-friendly interface
* 📱 Responsive iOS UI
* 🎨 Clean and reusable UI components

## 🛠️ Technologies Used

* **Swift**
* **UIKit**
* **Storyboard / XIB**
* **Auto Layout**
* **UICollectionView**
* **UITableView**
* **REST API / JSON** *(if applicable)*
* **Git & GitHub**
* **Xcode**

## 🚀 Getting Started

### Requirements

* macOS
* Xcode
* iOS Simulator or physical iPhone

### Installation

1. Clone the repository:

```bash
git clone https://github.com/anilyadavjnt/HotelBookingApp-iOS.git
```

2. Open the project in Xcode.

3. Select an iOS Simulator or connected device.

4. Build and run the project.
